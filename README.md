# راستا · نمونه‌ی هسته‌ی مالی (نسخه‌ی ۴)

نمونه‌ی تعاملی MVP هسته‌ی مالی راستا با دو کانسپت شیشه‌ای. دو کانسپت در همه‌ی صفحه‌ها ساختار و جریان کار جدا دارند و هر دو ساده نگه داشته شده‌اند:

- **دستیار:** دستیار هوشمند بخش اصلی است. هر صفحه با گفت‌وگو شروع می‌شود و تاریخچه‌ی گفت‌وگوها نگه داشته می‌شود.
- **پیشخوان:** صفحه‌ها بر پایه‌ی جدول، فیلتر و کاشی ساخته شده‌اند و دستیار به‌صورت نوار فرمان یا پنل کناری در دسترس است.

رنگ فقط برای وضعیت‌ها و نمودارهاست. پس‌زمینه آرام است و فقط شیشه‌ای بودن رابط را نشان می‌دهد. هر دو کانسپت حالت روشن و تیره دارند.

## صفحه‌ها

- **داشبورد:** ویجت‌ها قابل افزودن، جابه‌جایی و حذف‌اند («شخصی‌سازی»). آخرین اسناد هم روی داشبورد است.
- **سند جدید:** با متن، صدا یا فایل واقعی (عکس، PDF، CSV، TXT، اکسل). فایل انتخاب‌شده خوانده و تحلیل می‌شود و سند پیشنهادی ساخته می‌شود.
- **اسناد:** فهرست اسناد با جست‌وجو، فیلتر، تأیید و تأیید گروهی.
- **جزئیات سند:** ردیف‌ها، پیوست، تاریخچه‌ی تغییرات، تأیید، ویرایش و برگشت برای اصلاح، و دستیاری که تغییر را از یک جمله پیشنهاد می‌دهد.
- **گزارش‌ها:** گزارش پیش‌فرض «نمای کلی سیستم» (کاربران، اسناد، بخش‌ها و فعالیت)، درخت گزارش‌ها و دستیار گزارش با تاریخچه.
- **تقویم مالی:** نمای ماه، هفته و برنامه، تعطیلات رسمی، تاریخ میلادی و قمری، فیلتر تقویم‌ها و دکمه‌ی «یادآوری جدید».
- **حساب کاربری و شرکت‌ها:** فهرست شرکت‌ها، ورود به هر شرکت، افزودن شرکت، اطلاعات شرکت فعال و کاربران.
- **تنظیمات:** ظاهر، کد حساب و سقف تأیید، تقویم‌ها و سال مالی، یادآوری‌ها و اعلان‌ها.

## فرض‌های این نسخه

1. خزانه‌داری جدا نیست؛ هر کار خزانه (چک، قسط، انتقال) به سند می‌رسد.
2. فقط پول ملی؛ حساب‌های ارزی در این نسخه نیست.
3. ذخیره و چاپ به ریال، ورود به تومان با معادل ریالی زنده.
4. سندهای بالاتر از ۵۰۰ میلیون ریال پس از ثبت منتظر تأیید مدیر مالی می‌مانند.
5. شناسه‌ی صیادی از عکس چک خوانده می‌شود. چک چهار وضعیت دارد.
6. ورود اطلاعات بانک از فایل اکسل و پیامک بانک.
7. شماره‌ی سند به سال و ماه وابسته است (`۱۴۰۵-۰۸-…`) و خودکار ساخته می‌شود.

همه‌ی داده‌ها نمونه‌اند.

## اجرا

```bash
npm install
npm run dev
```

## فونت

طراحی با **یکان بخ** انجام شده که فونتی تجاری است و فایل‌هایش در این مخزن قرار نمی‌گیرد. برای دیدن با فونت اصلی، فایل `YekanBakhFaNum-VF.woff2` را در `public/fonts/licensed/` بگذارید. بدون آن، صفحه با وزیرمتن نمایش داده می‌شود.
