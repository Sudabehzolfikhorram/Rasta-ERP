# راستا · کانسپت داشبورد و ثبت سند

دو کانسپت طراحی برای MVP هسته‌ی مالی راستا، با جریان‌های یکسان و دو متریال متفاوت:

- **کانسپت آرام:** سطح‌های مات، مینیمال و متمرکز روی داده.
- **کانسپت شیشه:** پنل‌های شیشه‌ای روی پس‌زمینه‌ی آبی‌سبز. جدول‌ها و داده‌های متراکم تقریباً مات می‌مانند تا خوانا باشند.

جابه‌جایی بین دو کانسپت از نوار بالای صفحه است.

## چه چیزهایی ساخته شده

- **داشبورد «امروز»:** خلاصه‌ی ایجنت تحلیل‌گر، شاخص‌ها با «چرا؟»، تقویم و یادآوری با یک جمله، نمودار نقدینگی با پیش‌بینی، و صف «منتظر تصمیم شما».
- **ثبت سند:** با یک جمله، از عکس فیش یا دستی. نگهبان سند هم‌زمان تراز، حساب‌ها، ماهیت، تکراری‌بودن، پیوست و دوره را بررسی می‌کند.
- **فرمان‌بار (Ctrl+K):** پرسیدن، رفتن به صفحه‌ها و ساختن پیش‌نویس سند از یک جمله.
- **تور:** پنج قدم برای هر صفحه، با کیبورد و بدون کتابخانه‌ی سنگین.

همه‌ی داده‌ها نمونه‌اند.

## اجرا

```bash
npm install
npm run dev
```

## فونت

طراحی با **یکان بخ** انجام شده که فونتی تجاری است و فایل‌هایش در این مخزن عمومی قرار نمی‌گیرد. برای دیدن با فونت اصلی، فایل `YekanBakhFaNum-VF.woff2` را در `public/fonts/licensed/` بگذارید. بدون آن، صفحه با وزیرمتن نمایش داده می‌شود. پیش از انتشار عمومی، مجوز وب از فونت‌ایران لازم است.

## فناوری

Vite، React 18، TypeScript، Tailwind، کامپوننت‌های shadcn/ui روی Radix، cmdk و lucide.
