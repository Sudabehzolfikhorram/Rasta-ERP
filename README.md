# راستا · نمونه‌ی هسته‌ی مالی (نسخه‌ی ۳)

نمونه‌ی تعاملی MVP هسته‌ی مالی راستا با دو کانسپت شیشه‌ای که ساختار داشبوردشان کاملاً با هم فرق دارد:

- **دستیار:** داشبوردی که با یک جمله شروع می‌شود. خلاصه‌ی امروز، جعبه‌ی «بگویید چه سندی بزنم»، چهار شاخص با «چرا؟»، تصمیم‌های منتظر و برنامه‌ی هفته.
- **پیشخوان:** چیدمان کاشی‌ای (bento) برای نگاه سریع: نقدینگی و پیش‌بینی، تأییدها، تقویم ماه، سنی مطالبات، ترکیب هزینه و وضعیت بستن ماه.

هر دو کانسپت حالت روشن و تیره دارند و از نوار بالا یا تنظیمات عوض می‌شوند.

## صفحه‌ها

- **داشبورد:** دو ساختار بالا.
- **سند تازه:** با متن، صدا یا فایل (فیش و چک). دستیار چند سؤال کوتاه می‌پرسد، بعد سند قابل ویرایش را نشان می‌دهد. «بررسی سند» تراز، حساب ردیف‌ها، تکراری‌بودن، پیوست، دوره و سقف تأیید را چک می‌کند. ثبت دستی هم هست.
- **اسناد:** دسته‌بندی بر اساس وضعیت و نوع، جست‌وجو، فیلتر زمانی، تأیید گروهی و جزئیات هر سند.
- **گزارش‌ها:** درخت گزارش، نمودارهای متنوع، فیلتر پیشرفته، خروجی CSV و PDF، و دستیاری کناری که کارهای چندمرحله‌ای (مثل ارسال صورت‌حساب به چند طرف) را قدم‌به‌قدم انجام می‌دهد.
- **تقویم مالی:** سررسیدهای مالیاتی، بیمه، چک و اقساط، با افزودن یادآوری با یک جمله و رفتن مستقیم به ثبت سند.
- **تنظیمات:** طول کد حساب در سه سطح، سقف تأیید، واحد ورود و نمایش مبلغ، کانسپت، حالت و حرکت‌ها.

## فرض‌های این نسخه

1. خزانه‌داری جدا نیست؛ هر کار خزانه (چک، قسط، انتقال) به سند می‌رسد.
2. فقط پول ملی؛ حساب‌های ارزی در این نسخه نیست.
3. ذخیره و چاپ به ریال، ورود به تومان با معادل ریالی زنده.
4. سندهای بالاتر از ۵۰۰ میلیون ریال پس از ثبت منتظر تأیید مدیر مالی می‌مانند.
5. شناسه‌ی صیادی از عکس چک خوانده می‌شود. چک چهار وضعیت دارد.
6. ورود اطلاعات بانک از فایل اکسل و پیامک بانک.
7. شماره‌ی سند به سال و ماه وابسته است (`۱۴۰۵-۰۸-…`) و خودکار ساخته می‌شود.

همه‌ی داده‌ها نمونه‌اند.

## اجرا

```bash
npm install
npm run dev
```

## فونت

طراحی با **یکان بخ** انجام شده که فونتی تجاری است و فایل‌هایش در این مخزن قرار نمی‌گیرد. برای دیدن با فونت اصلی، فایل `YekanBakhFaNum-VF.woff2` را در `public/fonts/licensed/` بگذارید. بدون آن، صفحه با وزیرمتن نمایش داده می‌شود.

Vite، React 18، TypeScript، Tailwind، کامپوننت‌های shadcn/ui روی Radix، cmdk و lucide.
